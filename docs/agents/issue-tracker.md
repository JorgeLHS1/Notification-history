# Issue Tracker Configuration

Este documento registra a convenção de rastreamento de tarefas e issues para o projeto Notification History.

- **Tracker**: GitHub Issues (repositório JorgeLHS1/Notification-history)
- **Comando / Mecanismo**: `gh issue create --repo JorgeLHS1/Notification-history` · `gh issue list` · `gh issue view <n>`

## Diretrizes para Agentes

- Ao criar novas tarefas ou registrar bugs, consulte este arquivo para saber se deve utilizar a CLI oficial (`gh issue create`), arquivos locais de markdown ou outro sistema externo.
- Toda branch criada deve referenciar o número ou identificador da issue correspondente sempre que aplicável (ex.: `feat/123-nova-tela` ou `fix/456-correcao-auth`).
