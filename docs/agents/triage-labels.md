# Vocabulário de Rótulos de Triagem (Triage Labels)

Este documento mapeia o vocabulário canônico de rótulos de triagem de issues no projeto Notification History:

| Papel Canônico | Rótulo no Tracker | Significado / Responsabilidade |
|---|---|---|
| `needs-triage` | `needs-triage` | Issue recém-aberta aguardando análise de escopo e priorização. |
| `needs-info` | `needs-info` | Aguarda informações adicionais do autor ou reprodução do problema. |
| `ready-for-agent` | `ready-for-agent` | Especificação completa, pronta para ser implementada por agente de IA. |
| `ready-for-human` | `ready-for-human` | Demanda decisão arquitetural, validação externa ou credencial humana. |
| `wontfix` | `wontfix` | Fora de escopo ou rejeitada fundamentadamente. |
