## 1. O Que Foi Implementado
UI Compose navegável: lista de conversas (app icon, título, última mensagem, horário, selo "Apagada" quando `deleted`), chips de filtro por app, tela de conversa (mensagens do mais antigo ao mais novo) e tela de configurações (captura por app + valores de retenção).

- **Estado Anterior**: Ingestor com superfície de consulta (`apps`, `conversations`, `messages`, `setCaptureEnabled`), sem UI.
- **Delta Desta Etapa**: toda a camada de apresentação. Nenhuma regra de negócio nova; o schema do banco continua na versão 1.

---

## 2. Decisões Tomadas & Justificativas
- **Ingestor injetado**: `NotificationHistoryApp(ingestor)` e a `UiViewModelFactory` recebem o `Ingestor` por parâmetro. A UI só lê via Ingestor (regra 7 do AGENTS.md).
- **Provider temporário**: `TemporaryIngestorProvider` cria um Ingestor singleton para a UI rodar sozinha. **T3** (Application class) deve apagar esse arquivo e fazer `MainActivity` usar o Ingestor da Application (uma linha em `MainActivity.onCreate`).
- **Sem navigation-compose**: três destinos; back stack mínima com `rememberSaveable` + `BackHandler`. Evita dependência nova. Trocar por navigation-compose se surgirem mais telas (busca, seleção).
- **Atualização por invalidação** (substituiu o polling de 2 s na v0.4.0): `RefreshOnChange` coleta `Ingestor.changes()` (observer do `InvalidationTracker` do Room, conflated) enquanto a tela está em `STARTED`; a tela só recarrega quando algo foi gravado. A lista de conversas busca as últimas mensagens numa única query (`HistoryDao.lastMessages`), sem N+1. Ver [correções da revisão](2026-11-review-fixes.md).
- **Chamadas bloqueantes** em `Dispatchers.IO` (injetável nos ViewModels, `Dispatchers.Unconfined` nos testes). `load()` é `suspend` para testes determinísticos.
- **Retenção**: apenas armazenada em SharedPreferences; a limpeza é do T7.
- **Sem ícones Material estendidos**: botões de texto (Voltar, Configurações) para não adicionar a biblioteca de ícones.
- **Trade-off**: ícone do app vem do `PackageManager`; sem `QUERY_ALL_PACKAGES`, apps não visíveis no Android 11+ caem para avatar com a inicial do nome.

## 3. Como Foi Implementado
- **Fluxo**: Ingestor -> `HomeViewModel`/`ConversationViewModel`/`SettingsViewModel` (`StateFlow`) -> telas em `Screens.kt`.
- **Filtro**: `HomeState.selected` (vazio = todos) é passado a `Ingestor.conversations(packages)`.
- **Captura**: switch -> `SettingsViewModel.setCapture` -> `Ingestor.setCaptureEnabled(pkg, enabled, label)`.
- **Strings**: todas em `values` (en) e `values-pt-rBR`.
- Chaves de configuração: ver `settings-keys` abaixo.

### Chaves de configuração (SharedPreferences `retention_settings`)
| Chave | Tipo | Padrão | Significado |
|---|---|---|---|
| `retention_general_days` | Int | 90 | Dias para manter notificações. `0` = nunca expira. |
| `retention_deleted_days` | Int | 0 | Dias para manter mensagens apagadas. `0` = nunca expira. |

Leitura: `RetentionSettings.from(context)`. Mensagens fixadas nunca expiram (regra do T7).
